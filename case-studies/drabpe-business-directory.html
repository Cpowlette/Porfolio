DRABPE Business Directory

A public directory platform and connected website presence for Durham Region Association of Black Professionals and Entrepreneurs.

This project record describes the public services, tools, and delivery work. Internal data, platform configuration, and non-public operational details are not published.

  1. Scope
  2. Public services
  3. Tools and technology
  4. Delivery
  5. Skills applied

Project scope

I designed and maintained the public business-directory experience and supported the wider DRABPE website. The work brought organization information and business listings into a clear, responsive public surface.

Public services

  • drabpe.org serves the organization website.
  • directory.drabpe.org serves the public business directory.

I set up these subdomains as part of the project delivery.

Tools and technology

  • Supabase
  • Neon Postgres
  • JavaScript
  • HTML
  • CSS
  • Subdomain configuration
  • Responsive design

Delivery record

  1. Planned the public information architecture for organization and business-listing content.
  2. Built and maintained responsive website and directory interfaces.
  3. Set up the public website and directory subdomains.
  4. Supported business profile creation, updates, content review, accessibility, SEO, and analytics work.

Skills applied

  • Database-backed web development
  • Information architecture and interface design
  • Domain and subdomain coordination
  • Accessibility and search optimization
  • Content operations and stakeholder support
