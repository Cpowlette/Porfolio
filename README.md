# Christian Powlette Portfolio

Professional portfolio website showcasing cybersecurity, cloud computing, networking, systems administration, and technical support experience.

Built using HTML, CSS, and JavaScript with no frameworks, dependencies, or build process required.

---

## Overview

This portfolio serves as a central location for:

- Professional background
- Technical skills
- Resume download
- Project showcases
- Case studies
- Certifications
- Contact information

The site is designed to be lightweight, responsive, and easy to maintain while demonstrating front-end development fundamentals and technical documentation practices.

## Local Development

Clone the repository:

```bash
git clone https://github.com/YOUR_USERNAME/portfolio.git
```

Open:

```text
index.html
```

in your browser.

No installation or build steps are required.

---

## Configuration

Before publishing:

1. Update `CONFIG.siteUrl` in:

```text
assets/js/main.js
```

2. Verify contact information in:

```text
index.html
```

3. Replace the resume PDF when a new version is available:

```text
assets/docs/Christian_Powlette_Resume.pdf
```

4. Review project and skills sections to ensure they reflect current experience.

---

## Deployment

### GitHub Pages

1. Push the repository to GitHub.
2. Open Repository Settings.
3. Navigate to **Pages**.
4. Select:

```text
Deploy from Branch
```

5. Choose:

```text
Branch: main
Folder: /root
```

6. Save changes.

GitHub will publish the site automatically.
